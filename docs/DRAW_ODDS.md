# 부화 확률표 (draw 단계별)

집중 길이 → **draw 횟수** 보상. 등급을 draw번 굴려 **가장 높은 등급을 채택**(best-of-N)하고,
그 등급 안에서 종을 뽑는다. 등급/종 가중치 자체는 불변 — 길이 보상은 오직 draw 횟수로만 준다.

- 단일 출처: `FocusReward`(draw 매핑) · `CreatureSpecies.roll(draws:)` · `Rarity.tierWeight`
- 이 문서는 그 규칙에서 계산한 값(파생). 규칙이 바뀌면 이 표도 다시 계산해야 한다.

## 1. 집중 시간 → draw

| 집중 시간 | draw | 비고 |
|---|---|---|
| 25분 (free / 포모도로 1블록) | 1 | 기본 |
| 50분 | 2 | |
| 75분 | 3 | |
| 100분 이상 | 4 | 상한(`maxDraws = 4`) |

> `draws = clamp(focusSeconds / 1500, 1...4)` — 25분(1500초)마다 +1 draw, 4에서 멈춤.

## 2. 등급 확률 (draw별)

단일 굴림 등급확률: Common 80% · Uncommon 10% · Rare 8% · Legendary 2%.
best-of-N 공식: `P(최고등급 = X) = P(단일 ≤ X)^N − P(단일 < X)^N`.

| 등급 | 1 draw (25분) | 2 draws (50분) | 3 draws (75분) | 4 draws (100분+) |
|---|---:|---:|---:|---:|
| Common    | 80.00% | 64.00% | 51.20% | 40.96% |
| Uncommon  | 10.00% | 17.00% | 21.70% | 24.65% |
| Rare      |  8.00% | 15.04% | 21.22% | 26.63% |
| **Legendary** | **2.00%** | **3.96%** | **5.88%** | **7.76%** |

**핵심: 오래 집중할수록 Legendary·Rare가 뚜렷이 오르고 Common은 내려간다.**
- Legendary: 2% → 3.96% → 5.88% → **7.76%** (25분 대비 약 3.9배)
- Common+Uncommon 합("흔한 편"): 90% → 81% → 72.9% → 65.6%

## 3. 종별 실제 출현 확률 (draw별)

등급확률 × 등급 내 상대가중(Common 닭55:슬라임25 / Rare 검은고양이5:황금병아리3 / Legendary 백호1:피닉스1).

| 종 | 등급 | 1 draw | 2 draws | 3 draws | 4 draws |
|---|---|---:|---:|---:|---:|
| 빨간 토종닭 (Red Hen*) | Common | 55.00% | 44.00% | 35.20% | 28.16% |
| 슬라임 (Slime) | Common | 25.00% | 20.00% | 16.00% | 12.80% |
| 아기 공룡 (Baby Dino) | Uncommon | 10.00% | 17.00% | 21.70% | 24.65% |
| 검은 고양이 (Black Cat) | Rare | 5.00% | 9.40% | 13.26% | 16.64% |
| 황금 병아리 (Golden Chick) | Rare | 3.00% | 5.64% | 7.96% | 9.99% |
| 백호 (White Tiger) | Legendary | 1.00% | 1.98% | 2.94% | 3.88% |
| 피닉스 (Phoenix) | Legendary | 1.00% | 1.98% | 2.94% | 3.88% |

\* 빨간 토종닭은 6표정(빨강/화남/질림/헬창/졸림/너드) 중 하나가 균등 랜덤 → 위 Common-닭 확률을 6등분해 각 표정으로 수집.

## 4. 검증

- 각 draw 열 합 = 100.00% (반올림 오차 내)
- `draws = 1`은 기존 단일 추첨과 완전히 동일 (하위호환)
- 상한 4 draw = 전설 폭주 방지 (100분+ 세션이 있어도 7.76% 고정)
- DEBUG: 마이페이지 `debugDraws` 카드로 draw 강제(1~4×), Force hatch로 종 강제 — 릴리스엔 없음
