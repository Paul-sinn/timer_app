# Hatcho 경쟁앱 벤치마킹 & 기능 제안 리포트

> 작성: 2026-10-22 · 관점: 프로덕트 매니저(PM) · **코드 변경 없음(조사·제안만)**
> 근거: Hatcho 코드/문서 검색 + 경쟁앱 App Store 설명 + 2차 기사. 경쟁앱을 직접 설치해 써보진 않았음.

---

## 0. 한줄 결론

Hatcho는 **"부화 순간의 설렘"(가챠·진화·성격 대사)** 은 경쟁앱보다 강하다.
대신 **① 매일 다시 열 이유 ② 앱 밖(잠금화면·홈화면)에서의 존재감 ③ 친구에게 퍼지는 장치** 가 비어 있다.
기능을 많이 늘리기보다 이 3개 구멍을 먼저 메우는 게 우선이다.

## 1. Hatcho 현재 기능 (코드·문서로 확인)

### 있는 것
| 영역 | 내용 |
|---|---|
| 타이머 | 일반 25/50/75분 + 뽀모도로(25분 집중/5분 휴식, 누적 1시간 부화) |
| 부화 보상 | 오래 집중할수록 추첨 횟수↑(25분=1회 … 100분+=4회, 최고 등급 채택) |
| 수집 | 도감 12칸 · 4등급(Common/Uncommon/Rare/Legendary) · 3단계 진화 |
| 캐릭터 | 성격별 대사(비꼬는 알 → 존중 → 자부심), 복귀 시 반응 대사 |
| 기록 | 이탈 추적(4단계) + 집중 점수 · 스트릭(연속일) · 주간/월간 차트 · 최근 세션 |
| 기타 | 로컬 알림 · 햅틱 · 화면 꺼짐 방지 · 충전 보너스 · 배경 테마 2종 · Apple 로그인 + Supabase 동기화 · 아이패드 지원 · 온보딩 |

## 2. Cat On Chair 분석

### 개요
- 의자에 앉은 손그림 고양이와 함께 집중하는 뽀모도로 앱 (iPhone·iPad·Watch·Mac·Vision)
- 핵심 루프: **집중 완료 → 고양이가 선물** / **포기 → 쓰레기**(혼내지 않음) → 선물·쓰레기를 **생선(게임 화폐)** 으로 팔기 → 가구·장식 구매 → 고양이 방 꾸미기
- 평점 **4.9 (469개)** · 광고 없음 · 11개 언어
- 매출: 첫 8~9개월 약 $80K, 현재 월 $16~20K *(2차 기사 추정, 검증 안 됨)*
- 타깃: **고양이 좋아하는 사람 + ADHD 커뮤니티**(비판하지 않는 톤이 호평)
- 업데이트 속도: 5월~10월 약 5개월간 **20회 가까이** 업데이트. Discord·Instagram 커뮤니티 운영

### 주요 기능
| 영역 | 기능 |
|---|---|
| 타이머 | 뽀모도로·카운트업 · "Keep Going"(뽀모도로 끝나고 계속 카운트업) · 자동 휴식 · 일시정지 · Super Strict(이탈 즉시 알림) · 플로팅 타이머(PIP) · 가로 모드 · 배터리 절약 모드 |
| 함께 집중 | 친구 초대 실시간 방 · 공개 방 목록 · 좌석 상태(휴식/자리비움) · 방장 권한 · 방 위젯 |
| 경제·보상 | 선물/쓰레기 → 생선 · 가구 세트 33종 · 긴 세션일수록 희귀 선물 확률↑ · 10번째 세션 무료 의자 · 월간 목표(목표 달성 시 원하는 가구/고양이 무료) · 일간/주간 퀘스트 · 업적 · 추천인 보상 |
| 주간 회고 | **매주 마지막 날 저녁 고양이가 편지를 보냄**(저장·공유 가능) |
| 꾸미기 | 고양이 여러 마리(개별 판매) · 코트(옷) · 2마리 모드 · 배경(직접 사진 포함) · 프리셋 20개 · 앱 아이콘 변경 |
| 시즌 | 할로윈 유령 고양이 · 가을/여름 선물 세트 · 기념일 스킨 |
| 소리 | 고양이 골골송·비·벽난로·파도·카페·브라운노이즈·로파이 · 믹싱/볼륨(Pro) · 수면 타이머 |
| 통계 | 기본(무료) · 일/주/월/년 상세(Pro) · 태그·할일별 통계 · 타임라인 · Game Center 리더보드 |
| 할 일 | 할 일·하위작업·반복·마감일 · 애플 미리알림 양방향 동기화 · Siri로 추가 |
| 차단 | 앱·웹사이트 차단(무료) · 허용 앱 목록 · 취침 잠금 · 예약 잠금(Pro) |
| OS 연동 | 잠금화면 위젯 · 홈 위젯 여러 종 · **Live Activity·다이내믹 아일랜드** · 단축어 · 제어센터·액션버튼 · 애플워치 · 건강/캘린더 연동 · iCloud 동기화·로컬 백업 |

## 3. 기타 유사 집중앱 벤치마킹

| 앱 | 핵심 장치 | Hatcho에 주는 교훈 |
|---|---|---|
| **Forest** | 포기하면 나무가 죽음 · Deep Focus(허용 앱 외 차단) · 친구와 같이 심기 · 태그 · 실제 나무 심기 | 실패의 **결과가 눈에 보여야** 끝까지 버틴다 |
| **Focus Friend** (Hank Green) | 콩 캐릭터가 집중하면 양말을 뜨고, 딴짓하면 **슬프게 풀어버림** · 콩 화폐로 방 꾸미기 · 광고 없음 · 이 데모 영상 하나로 **앱스토어 무료 1위** | **슬픈 순간 = 마케팅 영상**. Hatcho라면 "알이 식는" 연출 |
| **Finch** | 자기관리 할 일 완료 → 펫 성장·모험 · **위젯이 리텐션 핵심**이라는 분석 · 추정 D1 54% / D7 37% · 에디터 추천 | 홈화면에 **내 생명체가 보이게** |
| **열품타** | 과목별 스톱워치 · 측정 중 다른 앱 차단 · 스터디 그룹 랭킹 · 그룹원 실시간 공부/휴식 상태 · 자동 플래너 · 백색소음 | 한국 학생 시장은 **"같이 하는 느낌"** 이 크다 |
| **Focus Plant** | 집중하면 빗방울 → 식물 키우기 · 식물 컬렉션 · 쓰레기 치우기 월드 · 애플 건강 연동 | 화폐가 **쓸 곳**이 있어야 오래 간다 |
| **Study Bunny** | 공부할수록 토끼 성장 · 과목별 시간 · 할 일·플래시카드 | 전형적 "타이머 + 펫" 구조 |

> 용어: **리텐션** = 앱을 다시 찾아오는 비율. **D1/D7** = 설치 1일/7일 뒤에도 쓰는 사람 비율.

## 4. 우선순위 로드맵 (초보 1인 개발 기준 대략 난이도)

### 🟢 지금 — 싸고 효과 큼
| # | 기능 | 이유 | 난이도 |
|---|---|---|---|
| 1 | **리뷰 요청 팝업** (2~3번째 부화 직후) | 별점 = 앱스토어 검색 노출(ASO) | 반나절 |
| 2 | **부화 공유 카드** ("레전더리 피닉스 부화!") | 친구가 보고 설치하는 바이럴 루프 | 1~2일 |
| 3 | **생명체가 보내는 주간 편지** | 기존 대사 시스템 + 통계 엔진 재사용. 비꼬는 톤 = Hatcho만의 무기 | 2~3일 |
| 4 | **한국어 복원** (이후 일본어) | 번역 283개 백업 있음(`Localizable.ko-orphans-backup.json`) | 1일 |
| 5 | **크래시 리포팅 + 기본 지표** | 측정 없으면 뭐가 먹혔는지 모름 | 1~2일 |

### 🟡 다음 — 1.1 ~ 1.2
| # | 기능 | 이유 |
|---|---|---|
| 6 | **Live Activity / 다이내믹 아일랜드** — 알에 금 가는 모습 | Hatcho의 시그니처가 될 수 있음 |
| 7 | **홈 위젯(내 생명체) + 잠금화면 "집중 시작" 버튼** | Finch 사례: 위젯 = 리텐션 |
| 8 | **시즌 한정 알** (할로윈·겨울) | 재방문 이유 + 마케팅 소재. **반드시 무료**(유료 랜덤 = 루트박스 규정 3.1.1) |
| 9 | **이탈 시 "알이 식는" 연출** (돌아오면 다시 따뜻해짐) | 혼내지 않는 결과. ADHD 배려 + 공유각 |
| 10 | **세션 태그** | 통계 세분화. 새 필드는 **옵셔널**로만(유저 데이터 보호) |
| 11 | **Pro 결제** — 구독 + **평생 구매** 옵션 | 학생은 구독을 싫어함. Cat On Chair도 평생 $29.99 제공 |

> 6·7번은 Xcode에서 "Widget Extension" 타깃을 **메뉴로 추가**해야 함(pbxproj 손수정 아님). 앱과 데이터 공유엔 App Group 필요.

### 🔵 나중 — 1.3+
| # | 기능 | 메모 |
|---|---|---|
| 12 | **앱 차단** | 유료 전환 최강 기능. 애플 Family Controls 특별 허가(몇 주 소요) → **신청은 지금 미리** |
| 13 | **친구와 함께 집중** (같이 알 품기) | 서버 작업 큼 |
| 14 | 백색소음 · 퀘스트/업적 · 둥지 꾸미기(화폐) | 장기 콘텐츠 |
| 15 | 애플워치 · 애플 건강 연동 | 후순위 |

### ❌ 하지 말 것
| 기능 | 이유 |
|---|---|
| 할 일 목록 | Hatcho 정체성 = 알 부화 앱. 할 일 앱과 경쟁할 이유 없음 |
| 경쟁 랭킹 | 아늑한 분위기를 깸 + 시간 조작 치트 방어 부담 |
| Cat On Chair 규모 따라가기 | 그 앱은 556MB·기능 수백 개. 1인 개발로 물량전은 못 이김 |

## 5. 포지셔닝

| 앱 | 감정 키워드 |
|---|---|
| Cat On Chair | 아늑한 동반자 |
| Forest | 벌칙(나무가 죽음) |
| Focus Friend | 미안함(양말이 풀림) |
| **Hatcho** | **수집·진화의 설렘 (포켓몬 감성)** |

- 도감을 다 채운 뒤에도 할 게 있어야 함 → **시즌 알 · 희귀 색 변종 · 진화 아트 확장**이 정체성에 맞는 방향.
- ⚠️ Cat On Chair·Focus Friend 성공 요인 중 하나는 ADHD 유저에게 **"혼내지 않음"**. Hatcho의 비꼬는 톤이 **실패 순간**에 상처가 되지 않는지 점검 필요.

## 6. 한계 & 주의

- 경쟁앱은 직접 설치해 보지 않음 — App Store 설명·2차 기사 기준.
- 매출·리텐션 수치는 2차 출처 **추정치**.
- Hatcho 기능 목록은 앱 실행이 아니라 **코드 검색·문서**로 판단.
