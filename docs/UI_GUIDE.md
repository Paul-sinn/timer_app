# UI 디자인 가이드

> 본 앱은 SwiftUI로 구현하되, **디자인은 Figma에서 먼저** 진행한 뒤 Figma MCP로 코드에 반영한다.
> 모바일(iOS) UI/UX를 최우선으로 하고, macOS는 동일 디자인을 무난히 확장한다.

## 디자인 원칙
1. **알이 주인공이다.** 홈 화면 중앙의 알/타이머가 시선의 중심. 나머지 UI는 보조 역할.
2. **집중을 방해하지 않는다.** 세션 중에는 정보를 최소화하고, 잔잔한 애니메이션만 유지.
3. **귀엽지만 깔끔하게.** 캐릭터는 따뜻하고 귀엽게, 인터페이스는 다크모드 위에서 미니멀하게.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() / glass morphism | AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 과한 라운드 | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur 원형 장식) | 모든 AI 랜딩 페이지에 있는 장식 |

## 컴포넌트
### 카드
```
배경 #161616, 1px border #262626, 모서리 14pt, 내부 패딩 16pt
```

### 버튼
```
Primary: 채움 #FFFFFF, 텍스트 #0A0A0A, 모서리 12pt   (예: 타이머 시작)
Danger:  채움 없음, 텍스트/보더 #EF4444             (예: 세션 중단)
Text:    텍스트 #525252 → 활성 시 #D4D4D4
```

### 입력 필드
```
배경 #111111, 1px border #262626, 모서리 12pt, 패딩 좌우 16 / 상하 12
```

## 레이아웃
- 기준: 모바일 세로(iPhone). 안전영역(Safe Area) 준수.
- 정렬: 홈은 알 중앙 정렬(예외). 그 외 목록/설정 화면은 좌측 정렬 기본.
- 간격: 요소 간 12~16pt, 섹션 간 24~32pt.
- 하단 고정 탭바 4개 (Home / Collection / Progress / MyPage).

## 화면 트리
- **Home**: 중앙 알 + 그 위 타이머. 시작/중단 컨트롤. 부화 진행도(크랙 단계) 표시.
- **Collection**: 부화한 생명체 그리드. 레어도 표시. (1단계는 mock 이미지)
- **Progress**: 누적 집중 시간/세션 기록, 일·주 단위 통계.
- **MyPage**: 프로필, 계정(Apple/Google), 설정.

|------|--------|
| 타이머 숫자 | 대형 모노스페이스 계열, 굵게, #FFFFFF |

| 카드 제목 | footnote, medium, #A3A3A3 |
| 본문 | body, #D4D4D4 |

## 애니메이션
- 허용: 알의 미세한 idle 흔들림(루프), 크랙 발생 시 짧은 진동/크랙 트랜지션, 부화 시 1회 등장 애니메이션(0.4~0.6s), 화면 전환 fade.
- 그 외 과한 모션·글로우·연속 펄스 금지. 세션 중 모션은 최소화.

## 아이콘
- Lucide 아이콘 세트 사용 (SwiftUI에서는 SF Symbols 매핑 또는 Lucide SVG를 에셋으로 임포트).
- 탭바: Home / Collection / Progress / MyPage 각 1개 라인 아이콘.
- strokeWidth는 가늘게(1.5 상당). 아이콘을 둥근 배경 박스로 감싸지 않는다.
