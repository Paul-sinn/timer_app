# PRD: FocusEgg (가칭) — 알 부화 집중 타이머

## 목표
타이머를 켜고 집중하는 동안 중앙의 알이 시간에 따라 부화하여, 공부·작업에 몰입할 동기를 주는 자기개발 타이머 앱.

## 사용자
- 공부·작업·독서 등에 집중 시간을 확보하고 싶은 사람
- 단순한 타이머보다 "끝까지 버티게 하는" 정서적 보상(귀여운 생명체 부화)이 필요한 사람
- 1차 타깃: 모바일(iOS) 사용자. macOS는 무난하게 동작하는 수준으로 후순위 지원.

## 핵심 기능
1. **집중 타이머** — 타이머를 켜 집중 세션을 시작/유지/종료한다.
2. **알 부화 이벤트** — 일정 시간(기본 15분)마다 알에 금이 가고, 누적 시간에 도달하면 부화한다.
3. **확률 기반 생명체** — 부화 시 확률표에 따라 일반/레어 생명체가 결정된다.
4. **화면 꺼짐 방지** — iOS에서 집중 세션 동안 화면이 꺼지지 않도록 유지(허용 시).
5. **컬렉션** — 그동안 부화시킨 생명체들을 모아 본다.
6. **집중 기록(Progress)** — 누적 집중 시간/세션 기록을 본다. 화면을 끄지 않고 유지했는지를 기준으로 기록.
7. **계정/로그인** — Apple 로그인 + Google 로그인 (Supabase Auth 연동).

## MVP 제외 사항
- AI 기능 (추후 유료 기능으로 도입 예정 — 당장 미구현)
- 캐릭터 이미지 정식 에셋 (직접 생성 예정 → 지금은 mock 이미지로 자리만 확보)
- macOS 전용 최적화 (모바일 반응을 본 뒤 진행)
- 소셜/친구/랭킹 등 커뮤니티 기능

## 디자인
- **다크모드 고정** (기본이자 유일 테마)
- 귀여운 애니메이션 톤. 중앙의 알이 시각적 주인공.
- 무채색 베이스 + 알/생명체의 따뜻한 포인트 컬러 최소 사용
- 모바일 UI/UX 최우선. PC는 동일 디자인을 무난히 확장.

## 구현 순서 (중요)
기획은 본 문서 전체를 기준으로 하되, **실제 구현 순서**는 아래를 따른다.
1. 기능·로그인 등 아무것도 구현하지 않고 **프론트엔드 UI만 먼저** 구현한다.
2. 이 단계의 데이터는 **모두 dummy 데이터**로 채운다.
3. 그 다음 단계에서 실제 기능(타이머 로직·부화·확률·저장·로그인)을 구현한다.
