# Hatcho 달걀 깨짐 6단계 이미지

`Paul-sinn/timer_app`의 기존 달걀 6단계를 기준으로 다시 제작한 교체용 PNG 세트입니다.

## 런타임 이미지

`final/` 폴더의 6개 파일을 사용하세요.

| 순서 | 파일 | 상태 |
|---:|---|---|
| 1 | `fullegg.png` | 깨지지 않은 달걀 |
| 2 | `firstcrack_egg.png` | 작은 첫 금 |
| 3 | `secondcrack_egg.png` | 첫 금이 조금 확장됨 |
| 4 | `thirdcrack_egg.png` | 여러 방향으로 연결된 금 |
| 5 | `fourthcrack_egg.png` | 넓게 확장된 파손 |
| 6 | `abouttocrack_egg.png` | 윗부분이 벌어지기 직전 |

## 이미지 규격

- PNG, RGBA 투명 배경
- 캔버스: `941 × 1672px`
- 달걀 표시 높이: 약 `400px`
- 모든 프레임의 중심축: 동일
- 모든 프레임의 위·아래 기준선: 동일
- 프레임 교체 시 크기나 위치가 튀지 않도록 정규화됨

기존 파일명과 동일하므로 현재 앱의 이미지 참조를 유지한 채 교체할 수 있습니다.

`preview-6-stage.png`는 전체 진행 순서 확인용입니다.
`_source/egg_cracking_6_stage_sheet_chroma.png`는 생성 원본 시트이며 앱 번들에는 넣지 않아도 됩니다.
