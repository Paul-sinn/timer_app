# Hatcho 금빛 충전·부화 폭발 6프레임

새로 제작한 달걀 깨짐 6단계의 마지막 이미지인 `abouttocrack_egg.png`에서 자연스럽게 이어지는 부화 이펙트입니다.

## 파일 순서

| 순서 | 파일 | 역할 | 권장 표시 시간 |
|---:|---|---|---:|
| 1 | `4-2egg.png` | 약한 금빛 충전 | 0.60초 |
| 2 | `4-3egg.png` | 강한 금빛 충전 | 0.50초 |
| 3 | `4-4egg.png` | 윗껍질 첫 파열 | 0.13초 |
| 4 | `4-5eggopacity.png` | 폭발 가속 | 0.11초 |
| 5 | `4-6oppacity.png` | 폭발 정점 | 0.10초 |
| 6 | `4-7eggoppacity.png` | 파편 확산·캐릭터 전환 | 0.16초 |

권장 전체 흐름:

1. `abouttocrack_egg.png`를 0.30초 유지
2. 위 6개 프레임을 표의 시간대로 재생
3. 금색·흰색 플래시를 0.10초 표시
4. 캐릭터를 약 0.40초 동안 스프링 애니메이션으로 등장

폭발 프레임인 3~6번은 crossfade 없이 즉시 교체하는 편이 선명합니다. 1~2번 금빛 충전 구간에만 짧은 opacity·scale 보간을 적용하세요.

## 이미지 규격

- PNG, RGBA 투명 배경
- 캔버스: `941 × 1672px`
- 새 Crack 에셋과 동일한 중심축·바닥선
- 1~2번의 달걀 본체 높이: 약 `400px`
- 3~6번은 달걀 본체 크기를 유지하고 파편만 바깥으로 확장
- 기존 이펙트 파일명과 호환
